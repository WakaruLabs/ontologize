\begin{abstract}
% wakaru.sty sets the abstract in a box that does not break, so it must fit
% on the page it starts on or it moves to the next one whole
\small
Behavioral evaluation cannot settle what a model is trying to do, because a
model can behave differently when it detects that it is being trained or
evaluated. Auditing a model's goals requires identifying its internal
variables, including concepts no one has thought to name (the ontology
identification problem). Supervised probes and difference-of-means vectors
currently outperform sparse autoencoder (SAE) features at concept detection
and steering, but supervised methods only test concepts an experimenter
already suspects. Unsupervised SAEs struggle in part because of the form of
their features: each latent either fires or stays silent, feature absorption
makes silence uninformative, and effective steering vectors instead contrast
alternative values of a variable. We propose learning categorical variables
directly by decomposing a representation space into competitive classifier
heads, each of which assigns every input to one of $k$ entries associated
with a learned atom. Forcing a head from one entry to another swaps one
atom for another, an unsupervised analogue of a difference-of-means vector,
though swaps between arbitrary partitions of the same space steer their own
cells just as specifically. In preliminary experiments on SONAR and GPT-2,
trained heads learn contrastive atoms, a
1900-bit hard code reduces reconstruction error by at least 33\% relative to
a 160-latent $\topk$ SAE at the same bit budget (though wider or
entropy-coded SAEs reach lower error), an 800-bit hard code on GPT-2
recovers more next-token loss than a $k_{\mathrm{SAE}}{=}32$ SAE, and
head-level interventions compose nearly additively. However, the learned
variables are not yet identifiable: independent seeds reach the same
four-digit reconstruction error while sharing no heads past the first layer,
and input-space steps flip other heads as often as random steps of the same
norm. The one exception is a block
of slow heads trained on adjacent sentence pairs, which reproduces across
three seeds, though not yet head by head (matched NMI $0.41$
vs.\ a $0.005$ null). Because an audit or a
learned objective requires features that remain consistent across retraining,
identifiability rather than reconstruction fidelity is the binding constraint,
and our proposed work begins with paired-view objectives.
\end{abstract}
